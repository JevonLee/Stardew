# 星露谷功能复刻蓝图（deepseek 分支路线图）

## 已完成（现有代码）

- 玩家移动/状态机（idle/move/swing/axe/hoe/water/draft）+ 相机
- 背包/物品栏/工具栏（Bag/）+ 箱子（box）+ 鼠标拾取/拖拽（MouseItem）
- 地图：Farm、Town、MyHouse、Store，场景切换（change_scene_area）
- 时间系统：时分流逝 + 昼夜色调（TimeSystem）
- 存档：SaveManager + SaveComponents 组协议
- 作物：甜瓜（Placeables/Crops），place_component 放置
- 地形破坏：草、树、石头（Terrain/）
- 商店：Store + commodity + store_panel
- 对话：dialogue + dialogue_ui，Emily、猪
- 武器投射物：彩虹猫之刃、暗影焰刀、烈焰激光、剑气
- UI：开始菜单、工具提示、获得物品提示
- 掉落物 + 战利品表（FallObjects/）
- 音频管理（AudioManager）

## 开发原则

1. 按 P0 → P7 顺序推进，每批完成后 headless 验证（见 project-conventions）
2. 数据驱动：作物/敌人/物品/鱼 用字典/资源文件定义，代码不写死数值
3. 复用现有系统：掉落用 loot_table，交互用 click_area_component，存档挂 SaveComponents
4. 战斗尽量复用泰拉瑞亚素材与现有 projectiles/ 弹幕框架
5. 每个新系统独立目录，避免 Player 脚本膨胀

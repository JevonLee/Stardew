# Stardew
尝试deepseek harness + deepseek v4 flash拓展项目，结果不尽人意啊

## 1. 🎮 游戏内帮助 UI（按 **H**）

新增指南面板：基础操作键位、合成与材料获取、**全部 20 个 Boss 的召唤物配方表**、快速成长攻略、开发者功能说明——不用再翻聊天记录了。

## 2. 📜 面板滚动修复

- **合成面板**（80+ 配方）：现在可滚轮滚动（面板也调大了）
- **商店面板**（21 商品）、**旅行面板**（14 目的地）：同样可滚动
- 图鉴面板原本就有滚动 ✓

## 3. 🛠 开发者功能

- **F2：无敌模式**（开启/关闭提示，免伤）
- **F3：物品生成器**——扫描全部 **170 件物品**，列表点击即获得
- 配合屏幕右上角已有的存档/加载/时间按钮，测试内容非常方便
